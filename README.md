# rbndict.github.io

Professional portfolio of **Rhoann U. Benedicto** — Diploma in Information Technology student at PUP – Sto. Tomas, built to grow from a student site into a graduate-ready IT portfolio.

Live at: <https://rbndict.github.io/>

## Stack

- Bootstrap 5.3 (layout, components, utilities, dark mode)
- Bootstrap Icons
- Vanilla JavaScript for interactions
- Google Fonts: Poppins + JetBrains Mono
- Hosted on GitHub Pages

## Files

| File | Purpose |
| --- | --- |
| index.html | Content and Bootstrap structure |
| style.css | Design tokens and custom components layered on Bootstrap |
| script.js | Theme, particles, typing, reveals, skill bars, copy email |
| rhoann.png | Profile photo and favicon |

## Customize

- Colors and themes: CSS variables in `:root` and `[data-bs-theme="light"]` in style.css
- Skill levels: `data-level` attributes on the `.bar-fill` elements in index.html
- Typed roles: `ROLES` array in script.js
- Projects: duplicate a `col-md-6` card block in the projects section
- Contacts: hero social buttons and the contact cards

## Features

Responsive Bootstrap navbar with ScrollSpy, dark and light themes with persistence, interactive particle background, typing hero, scroll-reveal animations, animated skill bars, copy-email toast, back-to-top, skip link, reduced-motion support, and SEO/Open Graph meta tags.
